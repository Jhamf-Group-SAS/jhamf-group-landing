# Web Audit Skill

Audit a website for technical, UX, SEO and routing issues.

## Tasks

Analyze:

- broken routes
- blank pages
- navigation errors
- multilingual problems
- missing meta tags
- performance issues
- accessibility
- UI inconsistencies

## Detect

- routes returning blank pages
- components that render null
- broken internal links
- inconsistent layouts
- translation errors
- missing canonical tags
- missing OpenGraph tags

## Deliver

1. broken routes
2. blank pages
3. routing configuration problems
4. SEO issues
5. UX issues
6. performance issues
7. recommended fixes
